一、项目简介
本项目基于 C 语言 + 单链表 开发学生成绩综合管理系统，搭载文件持久化、快速排序、二叉搜索树 (BST) 查找、多条件检索、成绩统计、CSV 表格导出等完整功能，适配 Dev-C++ TDM-GCC 编译环境，可完成学生信息全生命周期管理。
核心数据结构：单链表存储学生主体数据；二叉搜索树用于学号高效检索。

三、核心功能清单
（1）学生基础信息管理
1.添加学生：录入学号、姓名、班级、性别、电话、3门课程成绩，自动计算总分、平均分，尾插法存入单链表
2.删除学生：根据指定学号检索并移除链表节点，释放对应内存
3.修改学生：按学号定位后，更新姓名、班级、三门成绩，同步重算总分 & 平均分
4.查看全部：遍历链表，格式化打印所有学生完整信息
（2）排序功能（快速排序）
链表无法直接快排，采用「链表→指针数组→快排→重新串联链表」方案：
 1.按学号升序快速排序：字符串 strcmp 比对学号
 2.按总分降序快速排序：浮点数值比对总分 排序完成后自动刷新全局链表头节点，展示排序结果。
（3）多条件检索查询
1 .BST 学号精准查找：将链表数据构建二叉搜索树，对数级效率检索指定学号学生
2.姓名模糊查询：利用strstr()匹配姓名关键字，支持模糊匹配
3.班级精准查询：输入班级名称，筛选该班级全部学生
4.平均分区间查询：自定义最低、最高平均分，筛选区间内学生
（4）文件持久化
1.保存数据：将整条链表数据写入data/student.txt
2.加载数据 ：程序启动自动读取 txt，清空旧链表后重建数据；文件不存在则提示空白数据启动
（5）成绩统计 & 数据导出
1.成绩分析报告：统计总人数、全体平均分、最高 / 最低总分，划分「不及格 / 中等 / 优秀」分段人数，控制台打印文字报告 + 柱状统计图
2.统计文件导出：分段人数、整体均值写入score_stat.txt
3.CSV 表格导出：生成学生成绩总表.csv，Excel/WPS 可直接打开，包含成绩等级字段

四、关键技术细节
（1）全局链表管理
全局变量 Student* head = NULL：链表头节点，所有模块共享数据源
extern Student* head;：在fileio.c、sort.c等文件外部声明，实现跨文件访问头节点
freeAllList()：程序退出前完整释放整条链表，杜绝内存泄漏
（2）二叉搜索树 (BST) 逻辑
1.依据学生学号构建 BST：学号更小存入左子树，更大存入右子树
2.searchBST()：递归查找目标学号节点；freeBST()：查询完毕释放整棵树内存，避免堆积
（3）快速排序实现逻辑
1.listToArray()：遍历链表，把所有学生节点指针存入二级指针数组
2.对数组执行标准快排（学号 / 总分两种比对规则）
3.排序后数组元素重新用next指针串联，覆盖全局head，还原有序链表
4.释放指针数组内存，仅保留链表结构
（4）CSV 文件适配 Windows 办公软件
导出 CSV 采用系统默认 GBK 编码，去除 UTF-8 BOM 头，保证 Excel、WPS 打开中文不乱码。
